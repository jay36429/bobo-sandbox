# Bobo

A tiny cart/pricing helper. Disposable sandbox repo used to verify that CommandOS Relay
can safely read a real GitHub repository, propose a change, ask for approval, and open a
pull request — without ever touching `main`.

Nothing here is production code. Nothing here is secret.

## Usage

```js
import { subtotal, applyDiscount } from './src/cart.js';
```
